# 論文用グラフ作成アプリ（figapp）v1.14

CSV をアップロードし、描き方と列を選び、軸・色・文字を整えて、PDF／SVG／PNG／TIFF と描いた値を保存するアプリです。
設定は JSON で保存・読み込みでき、同じ見た目を別のデータにそのまま使い回せます。
図の書式の初期値は Nature 系（Arial、7 pt、線 0.5 pt、外向きの目盛り）です。
画面は 日本語・English・Tiếng Việt・ไทย で使えます（サイドバーのいちばん上で切り替え）。
Web 版（Streamlit Community Cloud）と、Python もターミナルも要らない PC 版（Mac・Windows のアプリ）があります。

## v1.14 の変更点（PC 版：Mac・Windows のアプリ）
- **PC 版**：ダブルクリックで開くアプリにしました。Python・Anaconda・ターミナルは要りません。中身は Web 版と同じで、
  アプリの窓の中に同じ画面が出ます。データはその PC の中だけで扱い、外には送りません（下の「PC 版（Mac・Windows のアプリ）」）。
  - Mac（Apple シリコン、macOS 12 以降）は `.dmg`、Windows 10・11 はインストーラー（管理者の権限は不要）か ZIP。
  - 「色の一覧」はユーザーのフォルダ（Mac は `~/Library/Application Support/figapp`、Windows は `%APPDATA%\figapp`）に保存し、
    アプリを入れ替えても残ります。選んだ画面の言語も覚えて、次に開いたときもその言語で始まります。
  - 窓を閉じると終わります（保存していない図や設定は消えるので、終了の前に確認が出ます）。
  - PC 版の PDF・TIFF は、PC にある本物の Arial で描きます。
- GitHub の `v1.14` のようなタグを付けると、GitHub Actions が Mac と Windows で PC 版を作り、実際の窓で確かめてから
  Releases に置きます（`.github/workflows/desktop.yml`）。
- Web 版のサイドバーのいちばん下（版の番号の下）に、PC 版のダウンロードへのリンクを付けました。
- **保存ボタンを続けて押しても保存できるように**：PDF の次にすぐ SVG を押すなど続けて保存すると、2 つ目以降が保存されない、
  またはファイル名が番号になることがありました（Streamlit 1.52 以降。保存ボタンを押すたびに描き直して、作りかけのファイルの番号が
  変わっていたため）。保存ボタンを押しても描き直さないようにしました（Streamlit 1.43 以降。手元の 1.32 はこれまでどおり）。

## v1.13 の変更点（学生も使えるように）
- **画面の言語を 4 つから選べる**：サイドバーのいちばん上の「🌐 Language / 言語」で、日本語・English・Tiếng Việt（ベトナム語）・ไทย（タイ語）。
  ラベル・説明・選択肢・注意書き・チェックの表まで替わります。図に入る文字（軸のラベル、凡例など）は入力したままです。
  - URL の末尾に `?lang=en`（`vi`・`th`・`ja`）を付けて開くと、最初からその言語になります。留学生に渡す URL に便利です。
  - 言語を切り替えても、読み込んだ CSV や設定はそのまま残ります。
  - 訳は `i18n_text.py`（英語・ベトナム語・タイ語を 1 行ずつ並べた表）にあります。直すときはここを書き換えます。
- **パスワード**（公開するときだけ）：Streamlit Cloud の Secrets に `password = "…"` を書くと、最初にパスワードを聞きます。手元で動かすときは聞きません。
- **同時に何人で使っても図が混ざらない**ようにしました。描画（matplotlib）は 1 つのプロセスで共有するので、描く順番待ちの錠をアプリ全体で 1 つにしました
  （これまでは実行ごとに別の錠ができていて、同時に描くと文字の大きさなどが他の人の設定になることがありました）。
- **共有のサーバーでは、色の一覧の保存をその人の画面だけに**：Streamlit Cloud では「色の一覧」の「保存」が「この画面で使う」になり、
  アプリのフォルダの colors.csv は書き換えません（ほかの人の一覧が変わらないように）。「colors.csv を保存」で手元に保存できます。
  みんなで使う一覧は、管理者が GitHub の colors.csv を直します。手元で動かすときは、これまでどおりフォルダの colors.csv に保存します。
- **操作ごとの待ち時間を短く**：Streamlit 1.52 以降（公開用の 1.66.1 など）では、PDF・SVG・PNG・TIFF を保存ボタンを押したときに作ります（これまでは操作のたびに 4 つとも作っていました。描き直しは約 1.3 秒→0.35 秒）。手元の 1.32 では、これまでどおり先に作ります。
- 古い Streamlit（1.32）で言語を切り替えると、アップロード欄が作り直されて CSV が消えるため、その時点の CSV を作業ファイルの CSV と同じ扱い（× で外せる）で残すようにしました。
- `requirements.txt` を、動作を確かめた版（Streamlit 1.66.1 など）に固定しました。新しい版が出ても公開中のアプリが勝手に変わりません。

## v1.12 の変更点
- **積み上げ棒**：棒グラフのレイヤーに「棒の並べ方」を足しました。「横に並べる」（これまでどおり）、「積み上げ」、
  「100% 積み上げ」（x ごとの合計を 100 % にして積む。質量や個数のままでも割合で描ける）から選びます。
  - 同じ x の系列を、下から「系列の順」に積みます（順は「系列・色」タブの「系列の順」で変えられる）。
    粒度の区分（`<38 um`・`38-63 um`・`>63 um`）は、そのまま細かい順に並びます。
  - 「区画の中に値を書く」と「値の小数の桁」。区画に収まらない値（低すぎる・細すぎる区画）は書きません。文字の色は区画の色に合わせて白か黒。
  - 凡例は積んだ順の逆（いちばん上の区画が凡例の上）。100% 積み上げで凡例の位置が「自動」なら、枠の外（右）に置きます（枠の中に空きがないため）。
  - 100% 積み上げの縦軸は、範囲を指定していなければ 0–100 ちょうど。x ごとの合計が 100 からずれていれば（例：99.8）、100 % に揃えたことをプレビューの下に出します。
  - 積み上げでは誤差棒・個々の点・n は描きません。同じ x と系列の行が複数あれば、その平均を積みます。
  - 描いた値（CSV）に、区画の高さ（height）・下端（stack_bottom）・上端（stack_top）、100% 積み上げでは percent が入ります。
  - 1 つの x に積み上げ棒のレイヤーが 2 つ以上あれば、横に並べます（組成ごとの CSV など）。
- **割合の内訳の CSV は、読み込むと 100% 積み上げ棒になります**：x（温度など）の列・区分（粒度など）の列・値の列があり、
  x ごとに区分の値の合計がほぼ 100（98–102）のとき。横軸は項目の軸になります。
- ひな形「粒度の内訳（ふるい分けの質量%、100% 積み上げ棒）」と、入力テンプレート（sieve.csv）を足しました。
- CSV に ASCII で書いた値も、凡例と項目の名前では `um` → `µm`、`38-63 um` → `38–63 µm` にします
  （Excel で CSV を Shift_JIS のまま保存すると µ や – が化けるので、CSV は ASCII のままで構いません）。

## v1.11 の変更点
- **濃淡のいちばん薄い色を、白地とのコントラスト 3:1 以上に**しました（細い線や小さな記号が印刷・プロジェクターで消えない目安。WCAG 2.1 の非テキストの基準）。
  これまでの最初の色（青 `#A6CEE4`、朱 `#FDB576` など）は約 1.7:1 でした。
  - 青・朱・緑・灰の濃淡は、3:1 にちょうど届く濃さから始めて、いちばん濃い色まで使います（3 系列の青：`#519CCC`・`#1966AD`・`#08306B`）。
    viridis は明るい黄色の側を使わず、3:1 を保てるところまでにしました。系列が 1〜20 のどの数でも、すべての色が 3:1 以上です。
  - 始まりの濃さは matplotlib の色そのものから計算するので、版が違っても 3:1 を下回りません。
  - ひな形（散布図・スペクトル・治癒率）の薄い青も同じ濃さに直しました。棒グラフの灰色の棒は面なので、そのままです。
- **薄すぎる色に注意書き**：線や記号で描く系列の色が 3:1 未満だと（黄・橙・空色などを選んだとき）、色の欄の下に「白地とのコントラストが 1.3:1 …」と出ます。
  描画は変えません。棒だけで描く系列には出しません。
- 前に保存した設定（.json／.zip）の色はそのままです。「系列・色」タブの「色を当てはめ直す」で新しい濃淡になります。

## v1.10 の変更点
- **文字の飾りをキーで**：入力欄で文字を選んで、Ctrl+I で斜体、Ctrl+B で太字、Ctrl+,（カンマ）で下付き、Ctrl+.（ピリオド）で上付き（Mac は ⌘ でも可。Word の Ctrl+= と Ctrl+Shift+= も使えます）。
  入力欄では `<i>l</i>`、`<b>…</b>`、`_{i}`、`^{2}` のような記号で出て、Enter で図に反映されます。直接書いても同じです（`<sub>`、`<sup>` も可）。
  例：`Initial crack length, <i>l</i>_{i} (µm)`、`Absolute crack-length reduction, Δ<i>l</i> (µm)`。キャプション用の文では飾りを外します。
- **色を名前で選ぶ**：色のピッカーの隣に「色の名前」を足しました（レイヤーの中と「系列・色」タブ）。一覧はアプリのフォルダの `colors.csv`（1 行に「名前,#RRGGBB」）で、
  はじめから Okabe–Ito の色（青・朱・緑…）と、最後に「750 °C・950 °C・1050 °C」が入っています。「系列・色」タブの「色の一覧」で足して「保存」すると、次に開いたときも同じ一覧になります。
  温度や組成の名前で登録しておけば、どの図でも同じ色を名前で選べます。名前で選んだ色は、設定と作業ファイルに名前ごと残ります
  （名前で選んでいない色は、一覧で先に出てくる同じ色の名前を、なければ「その他（ピッカーで選ぶ）」を表示します）。
- 色・色の名前・凡例の名前と、記号・線を **2 段に並べ直しました**（狭い画面でも名前が切れないように）。「系列・色」タブは系列ごとに枠で囲みます。
- **個々の点の横の散らし**の初期値を 0 にしました（x の真上に一列）。重なりを散らしたいときだけ「大きさ・文字」タブで値を入れます。

## v1.9 の変更点
- **近似線**：「平均 ± 誤差」と「散布図」のレイヤーで、「近似線」から 直線 y = a + bx・原点を通る直線 y = bx・2 次式・べき乗 y = a·x^b・指数 y = a·e^(bx)・対数 y = a + b·ln x を選べます。
  系列ごとに最小二乗で当てはめた線を描きます。
  - 「近似に使う値」：個々の値（薄い点も含めたすべての行。ふつうはこちら）か、平均の点か。
  - 「近似線の種類」（破線・実線・点線・一点鎖線）、「式と R² を図に書く」（位置は「凡例・注記」タブの「近似式の位置」）、「軸の端まで伸ばす」。
  - 係数・R²・点の数は、プレビューの下の「近似の結果」と、描いた値（CSV）に出ます。
  - べき乗と指数は、対数をとって直線で当てはめます（y が 0 以下の点は使いません）。R² は当てはめに使った点で計算します。
- （1.9.1）グループの列を使う（x が測った値の）レイヤーでは、「系列を横にずらす量」も効かないようにしました。平均も個々の点も、いつも実際の x の位置に描きます（個々の点の横の散らしは 1.7 から効きません）。
- **平均をつなぐ線の種類**：系列の列がない「平均 ± 誤差」のレイヤーで、色・凡例の名前・記号の隣の「つなぐ線」から実線・破線・点線・一点鎖線を選べます（「系列・色」タブの「線」と同じもの）。

## v1.7 の変更点
- **x が測った値のとき、荷重などのグループごとに平均 ± SD**：「平均 ± 誤差」のレイヤーの「グループの列（x が測った値のとき）」に荷重の列を選ぶと、
  荷重ごとに x（例：初期き裂長さ）と y（例：閉じた量）の両方の平均 ± 誤差を出し、平均の位置に縦と横の誤差棒を描きます。

- **自分で計算した SD を使う**：「誤差棒」を「列の値を使う」にすると、y の誤差の列に加えて「誤差の列（x、任意）」も選べます（横の誤差棒）。
- ひな形「き裂の閉じた量と初期き裂長さ」と、その入力テンプレート（closure.csv）を足しました。
- 描いた値（CSV）の n を整数で書くようにしました（3.0 → 3）。

## v1.6 の変更点
- **CSV を読み込むと、レイヤーが自動でできる**：CSV 1 つにつきレイヤーを 1 つ作り、すぐに図が出ます。
  - x は 1 列目、y は 2 列目の数値の列です。同じ x の値が繰り返されていれば「平均 ± 誤差」、x がすべて違えば線（30 点以上で順に並んでいるとき）か散布図で描きます。
    文字の列（例：composition）があれば、その列で色分けします。描き方・列は「レイヤー」タブで変えられます。
  - 新しい CSV を先に入れてから古い CSV を外すと、古いレイヤー（色・凡例の名前などの設定）のまま新しい CSV に切り替わり、新しい CSV 用に自動でできたレイヤーは消えます。
  - 「設定を初期化」でも、読み込んでいる CSV のレイヤーを作り直します。レイヤーを消したあとは「CSV ごとにレイヤーを作る」ボタンで作れます。
- **計算列を選んで作る**：「データ」タブの各 CSV の「計算列」で、計算（A ÷ B、1 − A ÷ B、A × 数、選んだ列の平均 など）と列を選んで「追加」を押します。式を書く必要はありません。
  - 追加する前に、式と結果の例（はじめの数行、最小・最大）が出ます。
  - 「作った列を y に使う」にチェックがあれば、この CSV のレイヤーの y がその列になります（軸のラベルも列の名前になります）。
  - 作った計算列は × で消せます。式を直接書きたいときは「式を直接書く」にチェックを入れます。
- **チェックで見つかった値を選んで除外**：「チェック」タブの「除外する値を選ぶ」で選んで「選んだ行を除外する」を押します。「除外している値」から戻せます。
  チェックは知らせるだけで、値を勝手に外すことはありません（数値でない・空のセルだけは描けないので自動で飛ばし、プレビューの下に知らせます）。

## v1.5 の変更点
- **軸のラベルが最初から入る**：レイヤーを作ると、x・y の列の名前が軸のラベルに入ります（`(um)` は `(µm)`、`(degC)` は `(°C)` に直します）。
  書き換えるまでは、レイヤーの列を替えるとラベルも替わります。書き換えたラベルはそのまま使い、「列の名前に戻す」で戻せます。
  前の版で保存した設定は、入っていたラベルをそのまま使います（空欄だった軸だけ列の名前が入ります）。
- **下付き・上付き**：軸のラベル、凡例の名前・見出し、書き込み、項目の名前で、`_{…}` が下付き、`^{…}` が上付きになります。
  例：`K_{IC} (MPa m^{1/2})`、`Yb_{2}Si_{2}O_{7}`、`Eu^{3+}`。上付きが数字だけなら `m^2`、`cm^-1` のように { } を省けます。
  下付きは { } が要ります（列の名前の `l_before` などをそのまま出すため）。`_`、`^` をそのまま出したいときは `\_`、`\^` と書きます。
  キャプション用の文では `Yb₂Si₂O₇`、`cm⁻¹` のような文字になります。
- **色の組み合わせ**：選んだらすぐ、すべての系列の色が替わります。「濃淡（色の順）を逆に」で、濃淡の組み合わせなら 1 つ目の系列を濃い色にできます（ほかの組み合わせでは色の順が逆になる）。
  系列ごとに変えた色を組み合わせに戻すときは「色を当てはめ直す」を押します。

## v1.3 の変更点
- **CSV を足す・外すと、レイヤーが 1 つ目の CSV に戻ってしまう不具合を直しました**（Streamlit 1.32 などの古い版で起きていた）。
  CSV を 1 つでも足したり外したりすると、すべてのレイヤーの「データ（CSV）」が一覧の先頭の CSV に戻り、前の CSV のまま描かれていました。
  計算列を足したときに、x・y の列が先頭の列に戻ることもありました。
- **外した CSV を使っていたレイヤー**：別の CSV に黙って切り替えず、描かずに知らせます（タブの上・レイヤーの見出し・プレビューの下）。
  - 1 つ外して 1 つ入れたとき（例：`10vol.csv` を外して `10vol_fixed.csv` を入れる）は、入れた CSV に自動で切り替えます。
  - それ以外は、タブの上の欄で代わりの CSV を選びます。列の名前が違う CSV に替えたときは、1 列目を x、2 列目を y にします。
- **サイドバーの「読み込んでいる CSV」**：読み込んでいる CSV と、それを使っているレイヤー（または未使用）の一覧です。
  Streamlit 1.32 のアップロード欄は 3 つずつしか表示せず、それより前に入れた CSV は欄の下の「Showing page 1 of 2」の矢印の先に隠れています。
- **「CSV をすべて外す」**：アップロード欄を空にします（レイヤー・軸などの設定は残ります）。同じ名前の CSV を入れ直せば、そのまま描けます。
- 同じ名前の CSV を 2 回入れたときは、後から入れた方を使い、警告を出します。中身が変わった CSV は、描き直したことを知らせます。
- 自分の CSV をアップロードすると、デモデータは自動で外れます。
- 中身が変わった CSV に「除外する行」が書いてあるときは、その行番号が今の CSV でも合っているか確認を求めます。
- 軸の最小・最大の外にあって図に出ていないデータがあると、プレビューの下に知らせます（ひな形を別のデータに使ったときなど）。

## v1.2 の変更点
- **枠と目盛り**：「軸」タブの先頭で、上の枠線・右の枠線を別々に付け外しでき、枠線を付けた辺に目盛りも付けられます。目盛りの向き（外向き・内向き）もここに移しました。
  v1.1 までは「大きさ・文字」タブの「上と右の枠も描く」1 つでした（保存済みの設定はそのまま引き継ぎます）。
- **個々の点の横の散らし**：個々の値の点は、重ならないように x の左右へわざと散らして描いています。その幅を「大きさ・文字」タブで変えられるようにしました（0 で x の真上に一列）。平均の点の位置は変わりません。
- **x の値の食い違いの警告**：平均 ± 誤差・棒グラフで、近いのに一致しない x（例：一方の CSV が 49、もう一方が 50）があると、プレビューの下と「チェック」タブに出します。揃っていないと、同じ荷重の点が横にずれて描かれます。
- 不具合の修正：x を log にして最小を空欄にすると、左端が 1 付近まで伸びていました。
- 新しく足したレイヤーの「系列を横にずらす量」の初期値を 0 に戻しました（v1.1 は 0.015）。

## v1.1 の変更点
- **データ（CSV）ごとに色を変えられる**：系列の列を（なし）にしたレイヤーは、レイヤーごとに 1 つの系列になります。
  CSV を 2 つ読んで 2 つのレイヤーにすれば、色・凡例の名前・記号が別々になり、レイヤーの中でそのまま変えられます（「系列・色」タブと連動）。

## 学生に使ってもらう（Streamlit Community Cloud で公開）
XRD Maker と同じく、公開リポジトリ＋パスワードで公開します（CSV やデータはリポジトリに入りません）。

1. GitHub の `A-Okawa/figapp` に、このフォルダの中身をそのまま置く（`app.py` がリポジトリの一番上）。
2. https://share.streamlit.io に GitHub アカウントでログイン →「Create app」→ GitHub のリポジトリから作る。
   - Repository：`A-Okawa/figapp`、Branch：`main`、Main file path：`app.py`
   - App URL：好きな名前（例：`figapp-imram`）
   - 「Advanced settings」：Python は 3.12。Secrets に次の 1 行（パスワードは研究室で決める）
     ```
     password = "研究室で決めた合言葉"
     ```
3. 「Deploy」。数分で `https://….streamlit.app` ができます。学生には URL とパスワードを伝えます。
   留学生には `…streamlit.app/?lang=en`（`vi`・`th`）を渡すと、最初からその言語で開きます。
4. 更新は GitHub の `main` を書き換えるだけで、数分でアプリにも反映されます。パスワードは Streamlit の「Settings」→「Secrets」で変えられます。

知っておくこと
- **12 時間だれも開かないと眠ります**。開いた人が「Yes, get this app back up!」を押すと、1 分ほどで起きます。
- **データ**：アップロードした CSV は、その人の画面の中だけで使われ、保存されません（ページを閉じると消えます。続きは「作業ファイルを保存」で）。

- **同時に使う人**：画面と設定は一人ひとり別です。描画は順番に行うので、大勢が同時に操作すると少し待つことがあります。
  無料の枠は、メモリが 690 MB〜2.7 GB 程度です（Streamlit の 2024 年 2 月時点の目安）。
- **パスワードなしで公開したいとき**は、Secrets に `password` を書きません。だれでも URL を知っていれば使えます。
- Streamlit Community Cloud 以外のサーバーで共有するときは、環境変数 `FIGAPP_SHARED=1`（または Secrets に `shared = true`）にして、
  色の一覧の保存をその人の画面だけにします。

## データの持ち方
どちらの形でも描けます。

| 形 | CSV | レイヤー | 色を変える場所 |
|---|---|---|---|
| 系列ごとに CSV を分ける | `5vol.csv`、`10vol.csv`（A 列 = x、B 列 = y、1 行 = 1 測定） | CSV 1 つにつき 1 つ（系列の列は（なし）） | レイヤーの中の「色」、または「系列・色」タブ |
| 1 つの CSV に系列の列を持つ | `composition` 列に 5、10 など | 1 つ（系列の列 = composition） | 「系列・色」タブ |

- 同じ x の測定値は行を重ねて入れます。同じ x の行がまとめて平均されるので、x には実測値ではなく設定値（設定温度・保持時間など）を入れます。
- CSV を分けるときは、同じ条件の x を同じ数字にします（例：両方とも 49 か、両方とも 50）。違っていると、同じ荷重の点が横にずれて描かれ、警告が出ます。
- ひな形「2 つの CSV を色分け」→「デモデータも」で、前者の形の例を合成データで試せます。

### x が測った値のとき（例：初期き裂長さと閉じた量）
1 行 = 1 本のき裂で、グループ（荷重）と単位（圧痕）を列に持たせます。平均と SD はアプリが計算します。

| temperature_C | load_N | indent | corner | l_before_um | l_after_um |
|---|---|---|---|---|---|
| 750 | 9.8 | 1 | 1 | 33.2 | 30.1 |
| 750 | 9.8 | 1 | 2 | 34.0 | 31.6 |

- レイヤー：x = l_before_um、y = 閉じた量（計算列で l_before_um − l_after_um）、系列 = temperature_C、グループ = load_N、単位 = indent、誤差棒 = SD。
  ひな形「き裂の閉じた量と初期き裂長さ」で「設定だけ読む」を押すと、この設定になります（入力テンプレートもサイドバーから保存できます）。
- 平均と SD をほかで計算した場合は、その表（例：load_N、l_mean、l_sd、dl_mean、dl_sd）を別の CSV にして、
  「平均 ± 誤差」のレイヤーで x = l_mean、y = dl_mean、誤差棒 = 列の値を使う（y：dl_sd、x：l_sd）にします。
  ただし、アプリは n を知らないので n の注記は使えず、き裂を除外しても平均と SD は変わりません。点と平均がずれないよう、できるだけ生データから計算させてください。

| レイヤー | CSV を読み込むと CSV ごとに自動でできる。描き方（平均 ± 誤差、棒（横に並べる・積み上げ・100% 積み上げ）、線、散布図、ティック）と、x・y・系列・まとめる単位の列。系列の列がないレイヤーは、その場で色・凡例の名前・記号を変えられる。n を書く場所。行の絞り込み、左右どちらの縦軸か、レイヤーごとの見た目の上書き。↑↓・複製・削除。 |

## n の表示
- **点ごと**：「レイヤー」タブの「n を書く」で、各点の上・各点の下・凡例（範囲）を選ぶ。形（`n = 5`、`(5)`、`5`）は「凡例・注記」タブで選ぶ。
  2 つの系列の点が近いときは、片方を上、もう片方を下にすると重なりにくい。
- **注記**：「凡例・注記」タブの「『Mean ± s.d., n = …』を図に書く」をオンにする。誤差棒の種類と n の範囲は、実際に描いた値から作るので、値を除外すると数字も変わる。
  「n が数えているもの」に `indentations`、`cracks` などを入れると、注記とキャプションの文に入る。
- **一覧**：プレビューの下の「n の一覧とキャプション用の文」に、点ごとの n の表と、図の説明文に使える文が出る。
- Nature 系の Reporting Summary では、n を数と単位で示すことに加えて、別々の試料を測ったのか同じ試料を繰り返し測ったのかの記載を求められる。
  同じ試料の複数のき裂なら、キャプションに `n = 8 cracks from 2 specimens` のように書く。

### 平均 ± 誤差の計算
「まとめる単位」の列（例：圧痕 ID）を指定すると、次の順に計算します。
1. 単位ごとに平均する（例：4 本のコーナー亀裂 → 1 圧痕の値）。
2. 単位の間で平均 ± SD／SE／95 % 信頼区間を出す。n は単位の数。

単位の列がなければ、同じ x の行の数が n です。単位の値（または各行の値）は、平均の後ろに小さな点で描けます。

アプリと同じ描画で、PDF／SVG／PNG／TIFF、描いた値、チェック結果を出し、n のキャプション用の文を表示します。
設定（.json）を使うときは、CSV のファイル名を設定に記録された名前と同じにしてください（作業ファイルなら CSV も中に入っています）。

## 書体
Streamlit Cloud には Arial がないため、Arial と字幅が同じ Liberation Sans で描きます（PC 版は、Mac・Windows にある Arial で描きます）。
- SVG は Arial を指定して保存するので、Illustrator で開けば Arial になる。
- PDF・TIFF を本物の Arial で出したいときは、Mac で手元実行するか、上のコマンドを使う。

## ファイル
| ファイル | 中身 |
|---|---|
| `app.py` | 画面 |
| `figcore.py` | 描画・集計・チェック。コマンドラインでも使える |
| `demo_data.py` | 合成デモデータ |
| `presets/` | ひな形の設定と、Fig. 1(a) の入力テンプレート |
| `colors.csv` | 名前で選べる色の一覧（1 行に「名前,#RRGGBB」。アプリの「色の一覧」からも編集・保存できる） |
| `i18n.py`、`i18n_text.py` | 画面の言語の切り替えと、英語・ベトナム語・タイ語の訳の表（日本語と英語は `app.py`・`figcore.py` の中に `ui('日本語', 'English')` で書いてある） |
| `requirements.txt`、`packages.txt`、`.streamlit/config.toml` | 公開用の設定 |
| `desktop/` | PC 版（Mac・Windows のアプリ）を作るためのもの：起動の仕組み、PyInstaller・インストーラーの設定、アイコン、確かめるスクリプト |
| `.github/workflows/desktop.yml` | タグ（`v1.14` など）を付けると PC 版を作って Releases に置く手順（GitHub Actions） |
