論文用グラフ作成アプリ figapp の PC 版です。Python もターミナルも要りません。データはその PC の中だけで扱います。

| | ダウンロードするファイル |
|---|---|
| Mac（Apple シリコン：M1〜、macOS 12 以降） | `figapp-*-mac.dmg` |
| Windows 10・11（64 ビット） | `figapp-*-windows-setup.exe`（インストーラー） |
| Windows（インストールできない PC） | `figapp-*-windows.zip`（展開して `figapp` フォルダの `figapp.exe`） |

### Mac
1. dmg を開き、`figapp` を「アプリケーション」へドラッグします。
2. アプリケーションの figapp をダブルクリックします。「開いていません」「確認できません」と出たら「完了」を押します。
3. システム設定 →「プライバシーとセキュリティ」を開き、下のほうの「“figapp”は Mac を保護するためにブロックされました」の「このまま開く」を押し、パスワード（Touch ID）を入れて、もう一度「このまま開く」を押します。
   （macOS 14 以前なら、figapp を control キーを押しながらクリック →「開く」→「開く」）
4. 2 回目からは、ダブルクリックだけで開きます。

### Windows
1. `figapp-*-windows-setup.exe` をダブルクリックします。「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押します。
2. 案内に沿って進めます（管理者の権限は要りません）。デスクトップの figapp のアイコンで開きます。

最初の 1 回は、開くまでに 1 分ほどかかることがあります。窓を閉じるとアプリは終わります。
アプリに Apple や Microsoft の署名が無いので、最初だけ上の確認が出ます。
